# colibri-templates

This artifact contains FreeMarker macros and Thymeleaf fragments, and no Java classes, so there is no API
documentation to generate. Maven Central requires a javadoc archive for every artifact; this file is its content.

Documentation: https://colibri-kit.io/java-templates.html
