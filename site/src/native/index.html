Colibri for React Native.

The same idea as Colibri on the web: a small set of well-made pieces, themed from one hue, with variants as plain props. No dependencies beyond React Native, no build step, no configuration.

npm install @colibri-kit/native
import { ColibriProvider, Screen, Stack, Heading, Button } from "@colibri-kit/native";

export default function App() {
  return (
    <ColibriProvider hue={160}>
      <Screen>
        <Stack gap="m">
          <Heading>Hello</Heading>
          <Button title="Continue" onPress={next} />
        </Stack>
      </Screen>
    </ColibriProvider>
  );
}
  • One hue, whole palette. Light and dark are computed for you, and follow the device.
  • 23 components, zero dependencies. Layout, text, buttons, forms, lists, dialogs, sheets and toasts.
  • Same words as the web kit. gap="s", variant="soft", tone="ok".
  • Accessible by default. Roles, states and 44-point touch targets are built in.
  • Typed. TypeScript declarations ship in the package.

The phone on this page is the real component code, running in your browser through react-native-web. Change the colour, switch to dark, open the dialog.
