Colibri Kit · Dashboards

Dashboards, plain HTML.

Built only from Colibri CSS primitives and tokens plus ~3 KB of SVG chart helpers. Work with no theme, then switch packs — every colour, radius, font and chart follows.

Analytics

KPIs with sparklines, traffic area chart with range switch, source donut, customers table, weekly bars + goal meter.

CRM

Pipeline KPIs, kanban stage lanes, monthly revenue bars, team activity feed, quota meters, deal-source donut.

Theme packs: themes/packs/ · <html data-kit-theme="glacier|ember|midnight"> · try ?theme=midnight. Source on GitHub.
